About ITlusions

ITlusions is an independent platform engineering shop focused on building secure, observable, and maintainable cloud infrastructure. We work on multi-tenant control planes, AI agent tooling, and security operations — in the open.

Engineering Focus

Multi-tenant cloud control planes with ARM-style resource hierarchies. Persistent AI memory via the BrainCell MCP/REST platform. Security operations tooling including OSINT, threat intel, and adversarial testing. Shared GitHub Actions workflows and reusable CI/CD infrastructure used across all ITlusions repos.
